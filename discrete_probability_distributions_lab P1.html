Laboratory Modules

Functional

Binomial Distribution

Models the number of successes in $n$ independent Bernoulli trials with constant probability $p$.

$$P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}$$

Poisson Distribution

Models the number of events occurring in a fixed interval of time or space given a constant average rate $\lambda$.

$$P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}$$

Geometric Distribution

Models the number of independent Bernoulli trials required to achieve the first success.

$$P(X = k) = (1-p)^{k-1} p$$

AI & Machine Learning Context

Binary Classifier Evaluation & Naive Bayes

In ML, each test instance evaluated by a binary classifier (e.g., Spam detection) can be viewed as an independent Bernoulli trial with accuracy probability $p$. The Binomial distribution models the likelihood of observing $k$ correctly classified instances out of $n$ evaluation samples, forming the foundation for calculating classifier confidence intervals and Bernoulli Naive Bayes feature likelihoods.
